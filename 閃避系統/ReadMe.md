## 內容

### 如何使用

1. 當玩家處於非創造、旁觀模式
2. 站立於地面
3. 短點擊`SHIFT`按鍵
4. 閃避結束進入`1.5`秒冷卻
5. 冷卻結束當下會有一清脆提示音

### 功能

1. 觸發閃避後會給予向玩家所視方向一個爆發力
2. 閃避期間獲得`0.25`秒`抗性V`
3. 期間受到非`強攻擊`之傷害，無視此次傷害造成的僵直<sub>datapack:stiff<sub/>
4. 期間受到`強攻擊`類之傷害，無視此次僵直，且減少`弱攻擊`之等量僵直，額外賦予二次衝刺，並刷新閃避冷卻至`0.5`秒
