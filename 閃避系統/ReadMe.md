## 內容

### 如何使用

1. 當玩家處於非創造、旁觀模式
2. 站立於地面
3. 短點擊`SHIFT`按鍵

### 功能

1. 觸發閃避後會給予向玩家所視方向一個爆發力
2. 閃避期間獲得`0.25`秒`抗性V`
3. 期間受到非`強攻擊`外之傷害，無視此次傷害造成的僵直<sub>stiff<sub/>
